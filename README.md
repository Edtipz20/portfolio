# Developer Portfolio

This is a personal developer portfolio website built with Next.js, React, TypeScript, and Tailwind CSS.

It includes:

- A home page with an introduction, skills, projects, and contact information
- Individual pages for portfolio projects
- A sign-in page and protected admin area
- Admin tools for adding, editing, and deleting projects and work experience
- PostgreSQL and Prisma for storing users, projects, and experience data
- Image uploads for project galleries

Run the project locally with:

```bash
npm install
npm run dev
```
